# SHAHMC Plugin

این پروژه پلاگین Paper/Spigot برای سرور SHAHMC است.

## ویژگی‌ها
- سیستم لابی حرفه‌ای
- NPC لابی
- بازگشت خودکار به لابی
- اسکبورد برای بازیکنان
- پول، سطح، پینگ و تعداد بازیکنان
- متن‌های فارسی و تمیز

## ساخت
```bash
mvn clean package
```

فایل نهایی در مسیر زیر ساخته می‌شود:
```text
target/shahmc-plugin-1.0.0.jar
```

## نحوه نصب
1. فایل JAR را در پوشه `plugins` سرور Paper/Spigot قرار دهید.
2. سرور را راه‌اندازی کنید.
3. با دستور `/setlobby` مکان لابی را تنظیم کنید.

## دستورات
- `/lobby` → رفتن به لابی
- `/setlobby` → تنظیم مکان لابی
- `/smp` → اطلاعات سرور
- `/npc` → ساخت NPC لابی

> اگر از Paper 1.20.1 یا Spigot سازگار استفاده می‌کنید، این پلاگین آماده اجراست.
